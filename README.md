# BartendingGame

Play Here:  
https://samuel5024.github.io/BartendingGame/  

**Controls**  
- WASD to move  
- LMB to pick up (interact) with bar objects  
- Left CTRL to crouch  
- Hold LMB or Left Shift to use the cocktail shaker  

***New Additions:***  
- Cursor UI remains on screen at all times  
- Added a cocktail shaker prefab  
- Added controls to use the cocktail shaker
- Interaction text disappears when you're not looking at an object
